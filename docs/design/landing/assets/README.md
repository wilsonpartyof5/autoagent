# Design Reference

This folder contains the design reference assets for the AutoAgent landing page.

## Assets

- `landing.png` - High-resolution screenshot from Loveable prototype showing the complete landing page design. Replace this whenever the gradient background or section styling changes so the reference stays current.

**Note**: The actual screenshot file needs to be added to this folder. The design implementation is based on the specification in `spec.md` and matches the Loveable prototype design.

## Usage

The screenshot serves as the visual reference for:
- Layout verification
- Color accuracy checks
- Component positioning validation
- Responsive behavior confirmation
