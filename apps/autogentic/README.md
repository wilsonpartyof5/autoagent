# Autogentic (iOS)

Native SwiftUI consumer app for Drevvy inventory search.

## Open in Xcode

```bash
open Autogentic.xcodeproj
```

## Backend

Talks to the dealer-dashboard APIs (e.g. `/api/query/chat-search`, `/api/inventory/*`).
Configure API base URL and keys in `Autogentic/Models/Config.swift`.
